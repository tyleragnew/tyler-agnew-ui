# Implementation Plan: Music Discography Browser

**Branch**: `002-music-discography` | **Date**: 2026-03-14 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/002-music-discography/spec.md`

---

## Summary

Replace the `/music` placeholder page with a live discography browser that
fetches albums from 7 Bandcamp artist pages using `bandcamp-fetch`, caches
results for 24 hours, and renders them as a clickable card grid. Selecting a
release opens a fixed-bottom Bandcamp iframe embed player. Falls back to a
manually-maintained static JSON when all Bandcamp fetches fail.

## Technical Context

**Language/Version**: TypeScript 5.x (strict mode)
**Primary Dependencies**:
- `bandcamp-fetch` v3.0.0 (ESM+CJS hybrid, discography scraper)
- `next/cache` — `unstable_cache` for caching non-fetch async functions
- `next/image` — cover art with explicit dimensions (CLS prevention)
- Existing: Next.js 15, React 19, Tailwind CSS v4

**Storage**: `lib/music-fallback.json` (static fallback, in-repo)
**Caching**: Next.js Data Cache via `unstable_cache` (`revalidate: 86400`)
**Testing**: Vitest + React Testing Library (unit) + Playwright (E2E)
**Target Platform**: Vercel (Next.js App Router, edge-cached Route Handler)
**Performance Goals**: Music page LCP ≤ 2.5s; player opens < 200ms after click
**Constraints**:
- No audio proxying — streaming handled entirely by Bandcamp iframe
- Player styling controlled by Bandcamp (no custom CSS inside iframe)
- `bandcamp-fetch` is a scraper; treat as fragile dependency

**Scale/Scope**: ~7 artists, estimated <100 total releases, single route `/music`

### Complexity Tracking

| Violation | Why Needed | Simpler Alternative Rejected Because |
|-----------|------------|-------------------------------------|
| External scraper dependency (`bandcamp-fetch`) | No official Bandcamp API exists | Manual JSON requires ongoing maintenance; scraper enables FR-007 (auto-refresh) |
| `unstable_cache` (internal Next.js API) | `bandcamp-fetch` bypasses native `fetch` so `next.revalidate` is unavailable | No stable public alternative for caching non-fetch async functions in Next.js |
