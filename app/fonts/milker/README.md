# Milker Font

Download the Milker font (Regular + Bold, woff2 format) from:
https://www.fontshare.com/fonts/milker

Place files here:
- Milker-Regular.woff2
- Milker-Bold.woff2

Then update `app/fonts/fonts.ts` to uncomment the `next/font/local` Milker definition
and remove the Nunito placeholder.
